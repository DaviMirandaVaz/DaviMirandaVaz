### 👨‍💻 Sobre Mim

Sou estudante de **Ciência da Computação no IFSULDEMINAS** e desenvolvedor focado na construção de **sistemas de gestão, APIs REST e aplicações multiplataforma** que resolvem problemas reais de negócio.

- 🏗️ Experiência prática desenvolvendo desde o **Back-End e modelagem de banco de dados** (**Java, Spring Boot, JPA/Hibernate, MySQL, SQLite**) até interfaces **Web, Mobile e Desktop** (**TypeScript, React Native, Expo, Electron**).
- 🔬 Atuação em **Iniciação Científica** com processamento de dados geoespaciais e sensoriamento remoto (imagens de satélite Sentinel-2 / QGIS).
- 💡 Base sólida em **Estruturas de Dados, Projeto e Análise de Algoritmos e Teoria dos Grafos** em **C/C++**.
